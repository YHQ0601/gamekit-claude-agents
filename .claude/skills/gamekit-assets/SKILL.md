# gamekit-assets

Purpose: produce profile-aware placeholder assets or a placeholder asset plan with replacement guidance. Default to co-locating placeholders next to the target asset location for demo and small-project speed, using `_PH` names and an artist brief.

## Workflow

1. Identify the active engine or runtime.
2. Confirm the gameplay purpose of the placeholder.
3. Choose a placement decision. Default to the target/final asset folder; use a dedicated placeholder/prototype folder only when scale or asset-pipeline risk justifies it.
4. Choose a simple, replaceable asset structure.
5. Use `_PH` naming for placeholder assets, `MAT_PH_` for placeholder materials when applicable, and `[AssetName]_ArtistBrief.md` for the replacement brief.
6. Add stable replacement anchors.
7. Include artist replacement notes, cleanup/replacement checklist, and validation steps.
