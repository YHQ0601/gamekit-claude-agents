# gamekit-plan

Purpose: classify a request before implementation so the workflow does not blindly execute everything.

## Workflow

1. Restate the user's goal.
2. Identify the active engine profile from project evidence or user intent.
3. Classify the task type.
4. Decide whether the task is necessary now.
5. Identify the smallest useful version.
6. Choose required workstreams and agent roles.
7. Decide whether implementation should start or whether user input is needed.

## Output Format

## Task Type

Code / Placeholder Asset / QA / Architecture / Knowledge / Mixed

## Active Engine Profile

Unity / Godot / Unreal / Web/JS / Mixed / TBD

## Necessity

Must do now / Can defer / Not recommended
